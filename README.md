# Snake Game

A classic Snake Game built using Python and the Turtle graphics module.

## Features

* Snake movement using arrow keys
* Random food generation
* Score tracking
* Collision detection
* Game over condition

## Technologies Used

* Python
* Turtle

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run `main.py`.
